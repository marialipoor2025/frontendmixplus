# Damoon Customer Club — TO-BE Redesign Mockups

Standalone HTML mockup suite for the proposed Damoon B2B Customer Club experience.

## How to open the tour

1. Open `index.html` in a browser (double-click or drag into Chrome/Edge/Firefox).
2. Click any page card, or start at [pages/01-login.html](pages/01-login.html) / [pages/03-dashboard.html](pages/03-dashboard.html).
3. Use the labeled sidebar and in-page links to walk the full journey.

No build step or server required — relative links work when opened as local files.

## Design principles (from UX audit)

- One shell, one journey — invoices stay **in-panel**
- Labeled right sidebar (not icon-only)
- Compact headers; dense tables/filters
- Deal status as pipeline: ارتباط اولیه → پیگیری → پیش‌فاکتور → فاکتور → تسویه
- Captcha only on login/register
- Navy brand `#0B2A4A`, soft blue-gray background, Vazirmatn, RTL Persian
