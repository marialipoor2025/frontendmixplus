# MixPlus Frontend

Marketplace frontend for household appliances (multi-seller, multi-brand). Built with **React + Next.js**. API lives in [`../backend`](../backend).

## Run locally

```bash
cd frontend
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Set `frontend/.env.local` to point at the API (see root README).
