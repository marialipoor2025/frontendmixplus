# Digikala seller scrape dumps

Generated by `scripts/scrape-digikala-seller.mjs` using `.browser-auth/digikala-seller.json`.

| File | Digikala API / page | MixPlus table |
|------|---------------------|---------------|
| `product-management.json` | `/api/v2/products/seller` → product-management | `catalog.DigiManagedProducts` |
| `product-list.json` | `/api/v2/product-creation/search/v2` → product/list | `catalog.DigiMarketplaceProducts` |
| `variant-management.json` | `/api/v2/variants` → variant-management | `catalog.DigiSellerVariants` |
| `reverse-dkp-22846237-microwave.json` | create wizard + PDP DKP-22846237 (category 5808) | `catalog.DigiCategoryFormSchemas` |
| `category-5808-validation-bind.json` | `/api/v2/product-creation/category/5808/validation` | (raw bind for form options) |
| `product-details.json` | Public Digikala `GET /v2/product/{id}/` (published PDP = registered panel content) | Enriches `Products` / specs / variants / PDP JSON |

Large dumps are gitignored; re-scrape after refreshing the Digikala seller session:

```bash
node scripts/scrape-digikala-seller.mjs
node scripts/scrape-digikala-product-details.mjs
```

On API startup:
- `DigiSellerScrapeSeeder` upserts seller list/variant dumps when `Seed:DigiScrape=true`
- `DigiCatalogFromScrapeSeeder` maps management → catalog when `Seed:DigiCatalog=true`
- `DigiProductDetailEnricherSeeder` maps `product-details.json` → specs/options/gallery/content when `Seed:DigiProductDetails=true`
